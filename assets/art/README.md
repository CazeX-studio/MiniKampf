# Art-Assets

Hier liegen neue, eigene Grafik-Assets für Asterfall. Die verbindlichen Regeln stehen in [ART_ASSETS.md](../../ART_ASSETS.md).

Der visuelle Stil wird separat festgelegt. Bitte keine bestehenden Dateien aus `assets/figuren/` oder `assets/0x72_dungeontileset_ii/` hierher verschieben, solange nicht geprüft wurde, ob Godot-Szenen, Skripte oder Import-Metadaten darauf verweisen.
