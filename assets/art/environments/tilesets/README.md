# Umgebungs-Tilesets

Hier liegen eigene, wiederverwendbare Kacheln für Böden, Wege, Wände, Wasser, Vegetation und Übergänge. Tilesize, Raster und Kollisionsanforderungen erst nach Abstimmung mit dem bestehenden Godot-Projekt festlegen.

Das bestehende Drittanbieter-Paket bleibt unter `assets/0x72_dungeontileset_ii/`.
